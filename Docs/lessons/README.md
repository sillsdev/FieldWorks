# FieldWorks lessons

This directory indexes durable engineering lessons from completed, rejected,
or substantially retired work. Lesson records preserve verified constraints
and evidence without authorizing an old implementation or creating a roadmap.

Before planning work in an indexed area, read its topic index. Recheck every
lesson against the current tree and current product behavior.

## Lesson areas

| Area | Use when working on |
| --- | --- |
| [Avalonia migration](avalonia-migration/README.md) | WinForms-to-Avalonia migration, coexistence, detail views, rule editors, interlinear editing, browse tables, activation, parity, and retirement |

## Adding lessons

Use [TEMPLATE.md](TEMPLATE.md). A human reviewer decides whether an observation
is a current principle, a hypothesis requiring revalidation, a rejected path,
or obsolete. Add a topic-area index entry using capability vocabulary so that
discovery does not depend on an old branch, ticket, type name, or PR number.

Lesson records do not replace current-tree discovery, legacy characterization,
domain-owner decisions, OpenSpec requirements, Jira execution records, or
normal build and test evidence.
