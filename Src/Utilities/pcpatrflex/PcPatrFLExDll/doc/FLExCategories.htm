The following table shows the category and some features that are automatically mapped from the FLEx category abbreviation (column 2) to what is needed in the PC-PATR grammar generated by PAWS (column 3). These features do not need to be added in the FLEx lexicon in the “PCPATR” field. If column 3 is (none) you will need to make an entry in FLEx in the "PCPATR” field directly following instructions in PAWS or in the help file in Use PC-PATR with FLEx to use that entry.
